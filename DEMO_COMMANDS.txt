# FraudShieldAI: Complete Demo Script

Complete step-by-step commands to run the entire FraudShieldAI system end-to-end.

## Prerequisites

- Windows PowerShell or Command Prompt
- Python 3.14.3 with virtual environment activated
- All dependencies installed (see requirements.txt)
- All model files present (autoencoder_model.pt, transformer_model.pt, gnn_model.pt)
- All data files present in data/ folder

## Troubleshooting

### Issue: Port 8000 Already in Use
```powershell
# Find and kill process using port 8000
netstat -ano | findstr :8000
taskkill /PID <PID> /F

# Or use different port
.venv\Scripts\python -m uvicorn 09_api:app --port 8001
```

---

### Issue: Streamlit Not Loading
```powershell
# Clear Streamlit cache
rm ~/.streamlit/cache -r

# Restart Streamlit
.venv\Scripts\streamlit run 10_dashboard.py --logger.level=debug
```

---

### Issue: CORS Error in HTML Dashboard
- Ensure FastAPI is running on http://localhost:8000
- Check browser console for specific error
- Verify CORS is enabled in 09_api.py

---

### Issue: Models Not Loading
```powershell
# Verify model files exist
ls -la *.pt

# Check file integrity
python -c "import torch; torch.load('autoencoder_model.pt')"
```

---

### Issue: Out of Memory
- Close other applications
- Reduce Streamlit cache size: `--client.maxMessageSize 20`
- Run on machine with >4GB RAM
